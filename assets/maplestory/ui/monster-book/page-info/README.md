# Page overlays and banners

The full overlays are unchanged PNG exports from Global MapleStory v102, under `UI/UIWindow2.img/MonsterBook/pageInfo`. The website uses only the banner crops.

| Unchanged export | Original WZ image | Cropped banner |
| --- | --- | --- |
| [book-info.png](book-info.png) | [`bookInfo0`](https://maplestory.io/api/wz/img/GMS/102/UI/UIWindow2.img/MonsterBook/pageInfo/bookInfo0) | [book-info-banner.png](book-info-banner.png) |
| [set-info.png](set-info.png) | [`setInfo0`](https://maplestory.io/api/wz/img/GMS/102/UI/UIWindow2.img/MonsterBook/pageInfo/setInfo0) | [set-info-banner.png](set-info-banner.png) |

Each banner is a 171 × 28 pixel crop starting at (9, 0) from the top left of its full overlay. The crop preserves the original pixels and transparency.

The `0` in `bookInfo0` and `setInfo0` is part of the original image name. Their siblings `bookInfo1` and `setInfo1` are separate images, not animation frames.
