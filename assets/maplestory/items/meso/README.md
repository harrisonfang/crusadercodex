# Bronze meso

These four frames come from the bronze meso icon (item 09000000) in **Global MapleStory v83**, archived by MapleStory.IO. The original artwork belongs to Nexon / Wizet. [WZ tree](https://maplestory.io/api/wz/GMS/83/Item/Special/0900.img/09000000/iconRaw)

The fetcher decoded each numbered Canvas node's base64 PNG and read its placement origin. The archive supplies no delay for these frames, recorded as `null` in the [animation manifest](animations.json).

From the repository root, run:

```sh
python3 dev/common/fetch_wz_sprites.py dev/maplestory/slime/fetch-meso.json
```
