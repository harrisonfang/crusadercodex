# Assets

[MapleStory](maplestory/) groups game artwork by category. A single-frame state uses its name, such as `hover.png`. When a sequence has multiple frames, the original WZ index goes before the extension, as in `hit-0.png` and `hit-1.png`.

Each asset's README identifies the game locale, client version, and WZ source of the original artwork. A derived image adds a descriptive suffix and its README records the source and edit. For example, [the book banners](maplestory/ui/monster-book/page-info/) use `-banner` for a crop of the adjacent full overlay.
