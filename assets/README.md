# Assets

The website uses the book, tabs, and cursors in [gms-v102/](gms-v102/).
The book is an unmodified 499 × 370 PNG with transparency.

[Source image](https://maplestory.io/api/wz/img/GMS/102/UI/UIWindow2.img/MonsterBook/backgrnd)
from MapleStory.IO's archive of the original MapleStory client artwork.

[pets/](pets/) holds installable pet bundles. Each folder contains a manifest and its
final sprite sheet. Only the sprite sheet is copied to the deployed site's pet directory.

The [slime](slime/), [meso](meso/), and [Magic Claw](magic-claw/) directories hold the
original frames and animation metadata used to build the MapleStory Slime locally.
Each directory's README identifies the game version and archive source.
