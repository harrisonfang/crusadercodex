# Left navigation

Unmodified GMS v102 Home bookmark PNGs from
`UI/UIWindow2.img/MonsterBook/LeftTab/0`, preserving the original state names.

The bookmark starts at book-relative (-15, 31). All 1,570 opaque selected-frame
pixels match the [released-v102 screenshot](https://mapleglobalnews.wordpress.com/2011/10/28/gms-v-102-rise-of-fellowship/)
at that position. Normal and mouseOver share the same asset origin; their
placement follows that origin. Those two frames have identical pixels.
