# Back button

Unmodified GMS v102 Back button PNGs from
`UI/UIWindow2.img/MonsterBook/UpTab`, preserving all four original states.

The button starts at book-relative (59, -13). All 418 visible opaque pixels of
the disabled frame match the [released-v102 screenshot](https://mapleglobalnews.wordpress.com/2011/10/28/gms-v-102-rise-of-fellowship/).
That source clips the top eight pixels; the website displays the complete asset.
The other states use the same origin and size.

[Original archive](https://maplestory.io/api/wz/export/GMS/102/UI/UIWindow2.img/MonsterBook)
