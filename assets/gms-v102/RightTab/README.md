# Right-side tabs

Unmodified GMS v102 PNGs from `UI/UIWindow2.img/MonsterBook/RightTab`.
Numbered paths and normal, mouseOver, and selected states are preserved.
The normal and mouseOver images have identical pixels in this version.

Relative to the 499 × 370 book, normal/hover images start at (477, 12 + 30 × index)
and selected images at (468, 12 + 30 × index). These include the 3px client offset
visible in the [v102 screenshot](https://mapleglobalnews.wordpress.com/2011/10/28/gms-v-102-rise-of-fellowship/).
The selected image's first 3 columns are clipped at render time, matching that
reference; the PNG is unchanged. The screenshot shows only the first tab selected;
the same clipping is applied to the other selected tabs using their shared geometry.
